# Острів суперсил — діагностика життєвих навичок

Індивідуальний онлайн-урок ≈25 хв для дітей 7–8 і 9–10 років. Дитина мандрує островом, а МІК веде урок з окремого пульта й показує дитині вкладку гри в Google Meet. Дві базові станції проходять усі, а ще 1–3 теми обирають батьки — ті, що їм найважливіші.

| Файл | Для чого |
|---|---|
| `pult.html` | **Пульт МІКа — не демонструвати.** Налаштування, сценарій кроку, кнопки введення, пропуски, звіт для батьків, PDF, надсилання в таблицю. |
| `index.html` | **Вікно гри «Острів суперсил»** — його МІК показує в Google Meet. Лише те, що бачить дитина: короткі питання й завдання великим шрифтом, без підказок, балів і таймерів. |
| `scenariy.html` | Повний сценарій для друку (перемикач групи 7–8 / 9–10). |
| `config.js` | Увесь контент, тексти, пороги, тривалості. Правте тут. |
| `core.js` | Стан, логіка станцій, оцінювання, рядок таблиці, синхронізація, самотести. |
| `hero-pixel.js` | Піксельний рушій персонажів (герой, Іскра, Боб, сова Ухта, силует гостя, вирази облич, предмети костюма зокрема «Браслет дружби»). |
| `sprites.html` | Службова сторінка для перевірки спрайтів (не для уроку). |
| `apps-script/Code.gs`, `docs/GOOGLE_SHEETS.md` | Запис результатів у Google Таблицю й PDF у папку на Google Диску. |

## Теми діагностики й таймінг (≈25 хв)

**Ядро — проходять усі:** Кіностудія (Емоції) і Похід (Планування). **Теми на вибір — батьки обирають від 1 до 3:**

| Тема для батьків | Ключ | Станція | Модуль програми |
|---|---|---|---|
| Впевненість | `vpevnenist` | Радіо Хвиля | Сміливий голос |
| Дружба | `druzhba` | Перший крок | Майстер дружби |
| Вміння домовлятися | `domovlenosti` | Ринок Боба | Свій вибір / Мирилка |
| Мирне розв’язання суперечок | `superechky` | Майданчик | Мирилка |
| Наполегливість | `napoleglyvist` | Сейф | Показую, що вмію / Моя справа |
| Гроші | `groshi` | Крамниця | Скарбничка |

**Порядок станцій:** Прибуття → Кіностудія → обрані теми в порядку таблиці → Похід → самооцінка й фінал. Радіо, якщо обране, завжди йде останнім перед Походом: дитина вже звикла до МІКа.

**Час:** Прибуття 1 + Кіностудія 4 + Похід 4 + Фінал 2 = 11 хв ядра, кожна тема ≈4 хв: 1 тема ≈15 хв, 2 — ≈19, 3 — ≈23. Тривалості — у `CONFIG.locations[*].minutes`, межа плану — `CONFIG.planMinutes`.

Відповідність «тема → станція → модуль», назви й описи для батьків — у `CONFIG.topics`; ядро — у `CONFIG.core`; тексти кроку вибору й ліміти — у `CONFIG.topicPick`.

### Теми з посилання: `?topics=`

Теми з форми запису можна передати посиланням — вони одразу будуть відмічені на кроці «Теми діагностики»:

```
https://<користувач>.github.io/LetMe_diagnostic/pult.html?topics=druzhba,vpevnenist
```

- ключі — з таблиці вище (`CONFIG.topics[*].key`), через кому, у будь-якому порядку й регістрі;
- невідомі ключі й повтори ігноруються, зайві понад 3 — відкидаються (лишаються перші за порядком таблиці);
- параметр діє лише на екрані налаштувань (і після «Нова діагностика»); МІК може змінити вибір вручну.

## Як провести урок

1. Відкрий `pult.html` у Chrome або Edge.
2. Заповни налаштування: **ім’я та прізвище дитини** (обидва обов’язкові, прізвище потрібне для пошуку в таблиці), **МІК**, групу, вік і стать (для форм слів «мріяв/мріяла»). Картка «Як це працює» пояснює, що на пульті, а що в грі.
3. Крок **«Теми діагностики»**: прочитай батькам фразу з картки й відміть 1–3 теми (четверту обрати не можна — з’явиться підказка). Під картками — «Діагностика займе ≈N хв». «Почати урок» неактивна, поки не обрано хоча б одну тему.
4. Натисни **«Відкрити вікно гри»**. Якщо браузер заблокував вікно — дозволь спливні вікна для сайту або відкрий `index.html` вручну **в тому самому браузері**.
5. Один раз клікни у вікні гри: так браузер дозволить звук.
6. Коли на пульті з’явиться «Вікно гри підключено»: у Google Meet натисни **«Показати екран» → обери вкладку або вікно «Острів суперсил»**. Не показуй увесь екран, інакше дитина побачить пульт.
7. «Почати урок». Список етапів зліва показує лише ядро й обрані станції, обрані теми — дрібно в шапці. Далі читай картку «Скажи дитині», вводь, що каже дитина, і тисни «Далі» (Enter). Під карткою — «Що перевіряємо», «Чого очікувати», «Якщо дитина мовчить або думає довго», «Якщо дуже активна й говорить довго».
8. Після фіналу пульт відкриває звіт для батьків (веб-сторінка зі скролом і панеллю навичок угорі): «Зберегти PDF». Якщо налаштовано таблицю, рядок і PDF надсилаються туди самі.

**Гарячі клавіші пульта:** Enter — «Далі»; пробіл — «+1 спосіб» у Кіностудії й «+1 зустрічне питання» у «Першому кроці»; Ctrl+Z — «Стерти останнє».
**Меню «⋯»:** «Нова діагностика» (з підтвердженням), «Відкрити вікно гри ще раз», звук у грі.

### Станції коротко

| Станція | 7–8 | 9–10 |
|---|---|---|
| Кіностудія (емоції) | комікс-розминка + складніший комікс; «Що допоможе заспокоїтися?» | кейс-розминка, «Контрольна» (що показує / що відчуває насправді), «Ранок не задався»; способи заспокоїтися |
| Сейф (наполегливість) | замок 1 (2 з 3) — розминка; замок 2 (3 з 5) — 2,5 хв | замок 1 (3 з 4); замок 2 (4 з 6) |
| Крамниця сови Ухти (гроші) | «Пікнік за 10 монет», «Без решти» | «Пікнік за 60 грн», «Що вигідніше?» |
| Похід (планування) | рюкзак за прогнозом; зламаний міст | розклад походу; злива й перепланування |
| Ринок Боба (домовленості) | мотузка, щоб переправити рюкзак; обмін з інвентарю | те саме + торг |
| Майданчик (суперечки) | «Правила», потім «Суддя» | «Компроміс» (розминка), «Чат класу» |
| Радіо (голос) | «Таємний гість»: питання від улюбленого героя дитини | те саме + «Думка за 30 секунд» |
| Перший крок (дружба) | «Як приєднатися» до гри незнайомих дітей; «Якщо сказали “ні”» (своїми словами, кілька кодів) | «Увійти в розмову» однокласників; «Розмова-пінг-понг» 60 с від імені однолітка |

У грі на мапі — лише станції сьогоднішнього маршруту, стежка з’єднує тільки їх. **Предмети костюма** видаються за порядком проходження (`CONFIG.costume.order`): перша пройдена станція — перший предмет зі списку, друга — другий тощо; корона — завжди у фіналі. Самооцінка (батарейки) і титул героя — лише серед навичок, які сьогодні оцінювали.

Таймери Кіностудії й Сейфа видно лише на пульті. На Радіо ім’я героя вписує МІК; у грі з’являється наш силует у плащі й масці з табличкою імені (жодних зображень відомих персонажів). «Без імені» — питає ведуча Іскра.

### Обмеження

- **Пульт і гра мають бути відкриті в одному браузері на одному комп’ютері.** Вони спілкуються через `BroadcastChannel` і `localStorage`, тому різні браузери чи пристрої один одного не побачать.
- Перезавантаження будь-якого з вікон прогрес не губить: стан зберігається в `localStorage`, а гра після завантаження сама запитує його в пульта.
- «Нова діагностика» стирає поточний стан. Перед нею збережи PDF.

## Як змінити тексти й пороги після пілоту

Усе лежить у `config.js`:

- `CONFIG.thresholds` — пороги рівнів. Наприклад, `emotions.frames = { l3: 0.83, l2: 0.58 }`: частка балів за кадри ≥83% → рівень 3, ≥58% → 2, інакше 1. Сейф: `hardSec` (таймер замка 2) і `stopSec` (зупинка раніше — слабкий сигнал).
- `CONFIG.content` — контент станцій (кадри, фрукти, товари, речі, репліки Боба, картки, чат, питання).
- `CONFIG.script` — що казати й робити на кожному кроці (пульт і `scenariy.html`): `say`, `check`, `expect`, `quiet`, `active`, `do`, `dont`.
- `CONFIG.task` — текст на екрані дитини для кожного кроку: `{ sit, q }`, де `sit` — 2–3 речення ситуації (хто герой, що сталося), `q` — повне питання окремим рядком. Для кадрів Кіностудії, покупок, завдань «Що вигідніше?», повідомлень чату й питань Радіо ситуація й питання лежать у самому контенті (`content.*`: поля `sit`, `q`, `say`).
- `CONFIG.script.bob.react` — що МІК каже після кожної репліки Боба; `content.radio.help` — шпаргалка «Як відповісти від імені гостя»; `QR` (на початку config.js) — питання інтерв’ю з навідними питаннями (`quiet`) і м’яким підсумком (`wrap`).
- `CONFIG.lore` — заставки станцій (можуть бути `{ '78': …, '910': … }`).
- `CONFIG.topics`, `CONFIG.core`, `CONFIG.topicPick` — теми для батьків, ядро, фраза й ліміти кроку вибору.
- `CONFIG.costume` — порядок предметів костюма (`order`), корона (`final`), назви в знахідному відмінку (`acc`).
- `CONFIG.thresholds.friend` — «Перший крок»: таймер пінг-понгу (`pingSec`) і пороги за кількістю зустрічних питань.
- `CONFIG.content.friend` — однолітки, репліки на екрані, шпаргалка відповідей однокласника для «Розмови-пінг-понгу».
- `CONFIG.codes` — кнопки-коди на пульті з еталонними відповідями (кнопка «Приклади»).
- `CONFIG.skills[*]` — назви, питання самооцінки (`selfQ`) і тексти звіту за рівнями.
- `CONFIG.iskra` — репліки Іскри в грі.
- `CONFIG.meetHint` — підказка про показ екрана в Google Meet.

## Google Таблиця (формат НМТ)

Аркуш «Проходження», один рядок на дитину. Налаштування — [docs/GOOGLE_SHEETS.md](docs/GOOGLE_SHEETS.md). Колонки: дата й час (`дд.мм.рррр гг:хх:сс`), ім’я, прізвище, вік, група (7–8 / 9–10), стать, МІК, **обрані теми** (через кому), тривалість (хв, 1 знак після коми), по 2 колонки на кожну з 8 навичок («— результат» і «— що робити»; «Дружба» — після «Голос і розмова»), самооцінка (`Емоції 2/3 | …`), кількість 🟢 / 🟡 / 🔴 по оцінених пробах, «Усі відповіді», висновок / маршрут, посилання на PDF, прихований id.

Кольори: 🟢 3 — сильна · 🟡 2 — росте · 🔴 1 — прокидається · ⚪ не оцінено (обрану станцію пропущено). Невибрана тема — `На курсі`, колонка «що робити» порожня.

## Звіт для батьків

1. **«Ви обрали: …»** — найдокладніший розбір кожної обраної й оціненої навички: результати проб із цифрами, що означає рівень, як це проявляється вдома й у школі, ідеї для дому, модуль курсу («Дружба → модуль «Майстер дружби»»).
2. **«Базові навички»** — Емоції й Планування, коротше.
3. Профіль (радар — від 3 оцінених навичок, інакше горизонтальні шкали), «Сильні сторони», «На що звернемо особливу увагу на курсі» (пріоритет — обраним темам), «Самооцінка й результат», «Стиль роботи» — лише з оцінених навичок.
4. **«Що ще розвиває курс»** — невибрані навички, а також обрані, але пропущені під час уроку: один рядок — назва, опис для батьків і «Цю навичку ми розглянемо на курсі» + модуль. Без рівнів, без «не оцінено» чи «пропущено».

Закріплена панель зверху: ім’я, титул, кольорові позначки лише оцінених навичок (обрані теми — першими).

### Формат колонки «Усі відповіді»

Коди розділені « | ». Пишуться лише станції сьогоднішнього маршруту (невибрані теми — не пишуться). Пропущена проба — `<код> пропущено`. ✅ — прийнятна відповідь, ½ — частково, ❌ — неприйнятна.

| Код | Станція | Формат і приклад |
|---|---|---|
| `K1…Kn` | Кіностудія, кадри | `K2 ❌ Радість → Сум, Злість` — обрано → прийнятні (після стрілки — лише якщо не ✅) |
| `K*` | Кіностудія, способи заспокоїтися | `K* способів: 3` |
| `S1` | Сейф, розминка (не оцінюється) | `S1 3 спр., відкрито` |
| `S2` | Сейф, складніший замок | `S2 5 спр., 1:42, без підказки, відкрито` — спроби, час, підказка, результат (відкрито / зупинилась / час вийшов) |
| `C1` | Крамниця, пікнік | 7–8: `C1 ✅ їжа ✅ вода`; 9–10: `C1 3,5 б.: батон і сир на трьох×1, сік 1,5 л×1` |
| `C2` | Крамниця, друга проба | 7–8: `C2 ✅ печиво в дорогу 7, ❌ квиток на човник 10 → 9`; 9–10: `C2 ✅ ✅ ❌ решта 33 → 37` |
| `P1`, `P2` | Похід | 7–8: `P1 потрібних 6/6 (+0 зайвих)`, `P2 обхід лісом`; 9–10: `P1 1 поруш. (…)`, `P2 0 поруш.` |
| `B1`, `B2` | Ринок Боба | `B1 спитала, що потрібно (ask→offer)`, `B2 чесний обмін [fair], торг: …` |
| `M1`, `M2` | Майданчик | 7–8: `M1 правила: ✅ по черзі по 5 хвилин, …`, `M2 суддя: …`; 9–10: `M1 компроміс: c1, c4 (обидві команди)`, `M2 чат: я, я, звин.; пояснює через почуття або наслідки` |
| `R гість` | Радіо | `R гість: Супер Кіт` або `R гість: без імені (Іскра)` |
| `R1`, `R2` | Радіо | `R1 відповіді 3,2,2; зустрічне питання — так`; `R2` (9–10) — що було в думці за 30 с |
| `F1` | Перший крок, проба 1 | `F1 код 3 (попроситься й запропонує своє)` — значення коду = рівень, у дужках — коротко (`CONFIG.codes.friendJoin` / `friendEnter`) |
| `F2` | Перший крок, проба 2 | 7–8: `F2 коди: 1 засмутиться, 2 інший варіант` — усі відмічені коди (рівень — максимальний); 9–10: `F2 питань: 2, ділиться своїм` — зустрічні питання за 60 с і чи ділилась своїм досвідом |

## Емодзі (Twemoji)

У Windows частина емодзі показується порожніми квадратиками, тому всі сторінки (гра, пульт, звіт, сценарій) підключають Twemoji: `@twemoji/api@15.1.0` з jsdelivr, картинки — з `https://cdn.jsdelivr.net/gh/jdecked/twemoji@15.1.0/assets/svg/`. Після кожного рендеру викликається `emojify()` (core.js), яка замінює емодзі на `img.emoji`. Монетки в цінниках і на пульті — власна піксельна монетка (`coinSVG()`), мотузка Боба — піксельний пропс (`ropeSVG()`). Без інтернету до jsdelivr сторінки працюють, просто емодзі показує системний шрифт.

Усі використані емодзі (99, для кожного перевірено наявність SVG у Twemoji):

## Самотести й перевірка

- `pult.html?test=1` — самотести логіки (пороги Кіностудії, Сейф із двома замками й 60 с, обидві проби Крамниці для обох груп, «Чат класу», «Таємний гість»; вибір тем: мінімум 1, максимум 3, `?topics=`; маршрут для різних наборів тем, Радіо — останнім; предмети костюма за порядком проходження; «Перший крок» для обох віків, зокрема кілька кодів у пробі 2 для 7–8; самооцінка й титул лише для оцінених навичок; звіт: обрані теми першими, невибрані з «Цю навичку ми розглянемо на курсі», ніде немає «не оцінено», радар чи шкали; рядок таблиці з «Обраними темами» й «На курсі»). Результати — в консолі браузера (F12) і в `window.__selftest`.
- `sprites.html` — усі голови з кожним предметом (зокрема «Браслет дружби») і в повному костюмі, Боб, сова Ухта, силует гостя, однолітки «Першого кроку», Іскра й вирази облич.

## Деплой на GitHub Pages

1. Репозиторій → **Settings → Pages**.
2. **Source:** «Deploy from a branch», гілка `main`, папка `/ (root)` → **Save**.
3. За 1–2 хв: пульт — `https://<користувач>.github.io/LetMe_diagnostic/pult.html`, гра відкривається з пульта, сценарій — `.../scenariy.html`.

Якщо репозиторій приватний, GitHub Pages потребує платного плану. Інакше репозиторій має бути публічним.
